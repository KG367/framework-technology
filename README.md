# Система планирования приготовления блюд

Консольное приложение для планирования домашнего питания.

## Текущее состояние

**Реализовано:**

- каталог блюд с ингредиентами (загрузка из `data/dishes.json`);
- поиск блюда по названию;
- подбор блюд по приёму пищи и максимальному времени готовки;
- планирование приёмов пищи на дату (задача + время);
- удаление приёма пищи из плана;
- автоматический список покупок (агрегация ингредиентов);
- подсчёт суммарной калорийности плана;
- обработка исключительных ситуаций и ошибок ввода;
- автотесты на pytest.

**Не реализовано (план развития):**

- учёт остатков в кладовой;
- недельное автоформирование меню;
- фильтры по аллергиям;
- экспорт списка покупок в файл.

## Структура проекта

```

/
├── README.md
├── requirements.txt
├── pytest.ini        — настройки pytest
├── main.py           — точка входа, меню
├── dishes.py         — работа с каталогом блюд
├── planner.py        — план питания и список покупок
├── storage.py        — чтение и запись JSON
├── utils.py          — даты и ввод пользователя
├── data/
│   ├── dishes.json   — каталог блюд
│   └── plan.json     — сохранённый план
└── tests/
├── conftest.py   — добавляет корень проекта в sys.path
├── test_dishes.py
└── test_planner.py

```

## Требования

- Python 3.9+
- Основной код использует **только стандартную библиотеку**.
- Для тестов и проверки стиля: `pytest`, `flake8` (см. `requirements.txt`).

## Установка (только для разработки)

```bash
pip install -r requirements.txt
```

## Запуск приложения

```
cd meal_planner
python main.py
```

## Пример работы

```
=== Система планирования питания ===
1. Показать каталог блюд
2. Найти блюдо по названию
3. Подобрать блюдо по времени
4. Добавить блюдо в план
5. Удалить блюдо из плана
6. Показать план
7. Список покупок
8. Статистика
0. Выход
Выберите действие: 4
Дата (ДД.ММ.ГГГГ): 17.09.2026
Приём пищи: завтрак
Название блюда: Омлет с сыром
Порций: 2
Добавлено в план.
```

## Тесты (pytest)

```
cd meal_planner
pytest
```

Или без установки pytest в систему:

```
python -m pytest
```

Проверка конкретного модуля:

```
pytest tests/test_planner.py -v
```

## Проверка стиля

```
flake8 meal_planner
```

## Модель данных (упрощённая)

| Сущность ↕▾ | Где хранится ↕▾ | Описание ↕▾ |
|---|---|---|
| Блюдо | `data/dishes.json` | название, приём, время, ккал |
| Рецепт | внутри блюда | ингредиенты с количествами |
| Задача | `data/plan.json` | дата, слот, блюдо, порции |
| Время | атрибут задачи | ISO-дата, слот приёма пищи |
