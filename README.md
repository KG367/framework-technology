# framework-technology
## Система планирования приготовления блюд
Позволяет снять с пользователя рутинную нагрузку, связанную с выбором блюд для приёма в пищу и превращает данный процесс из разрозненных действий в единый цикл.
**Целевой аудиторией** являются:
 - Занятые специалисты, готовые платить за подписку для экономии нескольких часов в неделю.
 - Семьи с детьми, которым необходимо чётко контролировать предпочтения всех членов семьи.
 - Спортсмены, требующие чёткие расчёты КБЖУ, шаблоны рационов.
 - Люди с медицинскими ограничениями на потребляемые блюда.
 - Экономные пользователи, желающие сэкономить на еде.

**Предметная область** - домашнее питание и её готовка.
Система описывает все этапы, начиная с выявления желаний пользователя и сопоставления их с возможностями, заканчивая сбором обратной связи.

#### Сущности:
 - Блюдо - готовая еда как объект выбора.
 - Рецепт - способ приготовления.
 - Задача - действие с исполнителем, сроком и статусом.
 - Время - дата/время с длительностью, дедлайнами и статусом.
 - Пользователь - владелец плана и исполнитель.
 - Ингредиент - абстрактный продукт.
 - Покупка - подвид задачи с указанием магазина и списка ингредиентов.

#### Функции:
Фильтрация по времени готовки, сложности, КБЖУ, бюджет, число порций.
Добавление собственных рецептов с указанием необходимых ингредиентов.
Автогенерация меню по заданным параметрам
Учёт разнообразия меню
Оценка стоимости и сравнение с бюджетом.
