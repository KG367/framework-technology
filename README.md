# Система планирования приготовления блюд

Консольное приложение для планирования домашнего питания.

## Текущее состояние

**Реализовано:**

- каталог блюд с ингредиентами (загрузка из [`./data/dishes.json`](./data/dishes.json));
- поиск блюда по названию;
- подбор блюд по приёму пищи и максимальному времени готовки;
- планирование приёмов пищи на дату (задача + время);
- удаление приёма пищи из плана;
- автоматический список покупок (агрегация ингредиентов);
- подсчёт суммарной калорийности плана;
- обработка исключительных ситуаций и ошибок ввода;
- автотесты на pytest;
- проверка типов через mypy;
- проверка стиля через flake8.

**Не реализовано (план развития):**

- учёт остатков в кладовой;
- недельное автоформирование меню;
- фильтры по аллергиям;
- экспорт списка покупок в файл.

```

/
├── README.md
├── requirements.txt
├── pyproject.toml    — настройки mypy
├── pytest.ini        — настройки pytest

├── dishes.py         — работа с каталогом блюд
├── planner.py        — план питания и список покупок
├── user.py           — профиль и ограничения питания

├── conftest.py       — добавляет корень проекта в sys.path
```

## Требования

- Python 3.9+
- Основной код использует **только стандартную библиотеку**.
- Для тестов и проверки стиля: `pytest`, `flake8`, `mypy` (см. [`./requirements.txt`](./requirements.txt)).

## Установка (только для разработки)

```bash
pip install -r requirements.txt
```

## Запуск приложения

```
cd meal_planner
python main.py
```
